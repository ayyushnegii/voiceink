# Contributing to VoiceInk

Thanks for your interest in making VoiceInk better.

## Getting started

```bash
git clone https://github.com/ayyushnegii/voiceink.git
cd voiceink
npm install
npm run dev
```

See [LOCAL_WHISPER_SETUP.md](LOCAL_WHISPER_SETUP.md) to set up the Python speech bridge.

## Ways to contribute

- **Bug reports** — Open an issue using the bug report template
- **Feature requests** — Open an issue with your use case
- **Code** — Fix bugs or build features from the issue tracker
- **Docs** — Improve setup guides, README, or code comments
- **Testing** — Run on different platforms and report issues

## Submitting a pull request

1. Fork the repo and create a branch: `git checkout -b fix/my-fix`
2. Make your changes and test on your platform
3. Open a PR with a clear description of what changed and why

Keep PRs focused — one fix or feature per PR. Large changes should be discussed in an issue first.

## Commit style

```
feat: add Hindi mid-sentence detection
fix: hotkey not registering on Windows 11
docs: update Whisper setup guide
chore: bump electron to 29
```

## Reporting security issues
